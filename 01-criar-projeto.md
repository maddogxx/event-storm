# Projeto Desktop de Event Storm em VueJs 3

## Como especialista em Event Storm, vamos criar um projeto Event Storm em VueJS atendendo os requisitos:
- Utilizar o framework Nuxt 3 com Typescript e TailwindCSS;
- Não crie arquivo CSS, o estilo deve ser definido direto nas tags com sintaxe tailwindCSS;
- Deve ter criação de dashboards, para confecção do fluxo em Event Storm;
- Deve ter criação de projetos que possuirá um conjunto de dashboards;
- Na edição do dashboard deve existir um painel lateral com os tipos de post-its com as cores no estilo Event Storm, onde seja possível clicar e arrastar para o dashboard;
- Na adição de post-its seja possível adicionar uma descrição;
- Deve persistir os dados em banco de dados sqlite;
- Seja possível exportar o dashboard em svg;
- Crie arquivo Dockerfile para facilitar a execução do sistema para outras pessoas.
