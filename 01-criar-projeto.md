# Projeto Desktop de Event Storm em Go

## Como especialista em Event Storm, vamos criar um projeto Event Storm em Golang atendendo os requisitos:
- Utilizar Fyne;
- Deve ter criação de dashboards, para confecção do fluxo em Event Storm;
- Deve ter criação de projetos que possuirá um conjunto de dashboards;
- Na edição do dashboard deve existir um painel lateral com os tipos de post-its com as cores no estilo Event Storm;
- Na adição de post-its seja possível adicionar uma descrição;
- Deve persistir os dados em banco de dados sqlite;
- Seja possível exportar o dashboard em svg;
